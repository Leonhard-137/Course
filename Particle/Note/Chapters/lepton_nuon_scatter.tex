\chapter{轻子-核子散射}
夸克模型认为强子由夸克构成，但是夸克模型自身不能描述强子内部夸克的动力学性质。
卢瑟福通过$\alpha$粒子轰击核子证实了原子的核式结构，探究强子内部结构同样可以使用类似的方法。$\alpha$粒子散射实验本质上是弹性散射，散射前后质子保持完整，
如果入射粒子能量极高，以至于让质子成为激发态甚至被“打碎”，就可以进一步探究质子的内部组分，这就是深度非弹性散射(Deep Inelastic Scattering, DIS)。

\section{弹性散射}
\subsection{弹性散射运动学}

电子与质子散射过程末态粒子原本具有8个独立参数。在计入粒子质壳约束（$p_3^2 \approx 0, p_4^2 = M^2$）、方位角轴对称性（1个）以及四动量守恒约束（4个）后，该过程的独立自由参数仅余1个。实验室系下，设置初末态动量如下：
\begin{align*}
    \n{极端相对论近似下忽略电子质量。}
    p_1 &= (E_1, 0, 0, E_1)  \\
    p_2 &= (M, 0, 0, 0) \\
    \n{此处 $M$ 实为 $E_4, \vec{p}_4$ 的函数，为简化表达直接记作 $M$。}
    p_3 &= (E_3, E_3\sin\theta, 0, E_3\cos\theta) \\
    p_4 &= (E_4, \vec{p}_4) 
\end{align*}

定义下述物理量描述散射性质：
\begin{itemize}
    \item \textbf{动量转移：} 虚光子四动量 $q = p_1 - p_3$，定义动量转移平方 $Q^2 \equiv -q^2 > 0$。
    \item \textbf{能量转移：} $\nu \equiv E_1 - E_3$，可以证明，对弹性散射满足 $Q^2 = 2M\nu$。\n{$\nu > 0$ 表征电子在散射中的能量损耗。}
\end{itemize}

\begin{derivationnote}[散射判定与Bjorken变量]
    利用末态强子系统的不变质量 $W^2 \equiv p_4^2$。由四动量守恒 $p_4 = p_2 + q$ 对两边取平方：
    \n{$2M\nu$ 项形式上对应轻子给核子传递的能量($T = \frac{p^2}{2m}$)，$W^2 - M^2$ 项对应产生新质量的能量，$Q^2$让质子产生反冲。}
    \begin{equation*}
        W^2 = (p_2 + q)^2 = p_2^2 + 2p_2 \cdot q + q^2 = M^2 + 2M\nu - Q^2
    \end{equation*}
    整理得动力学判定式：
    \begin{equation}
        Q^2 = 2M\nu - (W^2 - M^2) 
    \end{equation}
    由此定义无量纲的比约肯变量（Bjorken $x$）：
    \begin{equation}
        x \equiv \frac{Q^2}{2M\nu} = 1 - \frac{W^2 - M^2}{2M\nu} \n{取值范围 $0 < x \le 1$。}
    \end{equation}
    变量 $x$ 可以区分弹性和非弹性散射：当 $W = M$ 时，$x = 1$，对应弹性散射；当 $W > M$ 时，$x < 1$，对应非弹性散射。
    
    在弹性条件，四动量转移与能量转移满足 $q^2 = -2p_2 \cdot q$。
\end{derivationnote}

\n{这里符号差异源于度规 $(+---)$。当靶核极重或低能时，$q^2 \approx -\vec{q}^2$。}
此外根据三动量和四动量转移的关系，还可以定义描述反冲程度的参数$\tau$。
\begin{theorem}[三维与四维动量转移的关系]
在轻子-核子散射中，实验室系下的三维动量转移平方 $\vec{q}^2$ 与四维动量转移平方 $Q^2$ 满足如下普适关系：
\begin{equation}
    \vec{q}^2 = Q^2 \left( 1 + \frac{\tau}{x^2} \right)
\end{equation}
其中 $\tau = Q^2/4M^2$ 是一个洛伦兹不变量，可以描述散射的反冲程度，$x$ 为比约肯变量。
\end{theorem}

\begin{proof}
四动量转移q满足
\begin{equation}
    q^2 = \nu^2 - \vec{q}^2 = Q^2 + \nu^2
\end{equation}
比约肯变量 $x = \frac{Q^2}{2M\nu}$，能量转移由其表示为 $\nu = \frac{Q^2}{2Mx}$，代入上式：
\begin{align}
    \vec{q}^2 &= Q^2 + \left( \frac{Q^2}{2Mx} \right)^2 = Q^2 + \frac{Q^4}{4M^2x^2}
            &= Q^2 \left( 1 + \frac{Q^2}{4M^2x^2} \right) = Q^2 \left( 1 + \frac{\tau}{x^2} \right)
\end{align}
对于弹性散射，$x=1$，公式退化为 $\vec{q}^2 = Q^2(1 + \tau)$。在非弹性散射中，由于 $x < 1$，相同的 $Q^2$ 下需要注入更多的能量 $\nu$，从而导致三维动量的偏离被因子 $1/x^2$ 进一步放大。
\end{proof}

\subsection{形状因子}
早期的卢瑟福散射公式是在入射电子具有非相对论性、靶核（如质子）质量无穷大且不考虑其内部结构的理想条件下得到的。然而，真实的质子不仅具有有限的质量和自旋，更重要的是它具有内部结构。
这种非点状的内部结构由形状因子描述。

先在非相对论量子力学框架下做一个简单的讨论，假设质子质量 $M \to \infty$（静止），且不考虑自旋。此时，电子在质子产生的静电势场 $V(\bm{r})$ 中散射。

散射截面的本质是跃迁几率，根据费米黄金律，它与跃迁矩阵元 $M_{fi}$ 的模方成正比。假设电子从初态动量 $\bm{p}_1$ 跃迁到末态动量 $\bm{p}_3$，动量转移为 $\bm{q} = \bm{p}_1 - \bm{p}_3$。
如果质子内的电荷并非集中在一点，而是以密度 $\rho(\bm{r})$ 分布，则势能函数为：
\begin{equation}
    V(\bm{r}) = \int \frac{Z e^2 \rho(\bm{r}')}{4\pi \abs{\bm{r} - \bm{r}'}} \dd[3]{\bm{r}'}, \quad \text{其中} \int \rho(\bm{r}) \dd[3]{\bm{r}} = 1
\end{equation}
散射前后电子都是平面波形式，散射矩阵元 $M_{fi}$ 为：
\begin{equation}
    M_{fi} = \mel{\psi_f}{V(\bm{r})}{\psi_i} = \int e^{-i\bm{p}_3\cdot\bm{r}} V(\bm{r}) e^{i\bm{p}_1\cdot\bm{r}} \dd[3]{\bm{r}}
\end{equation}
令 $\bm{R} = \bm{r} - \bm{r}'$，积分可以分解为点状质子散射矩阵元乘以一个和内部结构有关的因子（形状因子）：
\begin{align}
    M_{fi} &= \iint e^{i\bm{q}\cdot(\bm{R} + \bm{r}')} \frac{Z e^2 \rho(\bm{r}')}{4\pi R} \dd[3]{\bm{R}} \dd[3]{\bm{r}'} \notag \\
    &= \underbrace{\left( \int e^{i\bm{q}\cdot\bm{R}} \frac{Z e^2}{4\pi R} \dd[3]{\bm{R}} \right)}_{(M_{fi})_{\text{point}}} \cdot \underbrace{\left( \int \rho(\bm{r}') e^{i\bm{q}\cdot\bm{r}'} \dd[3]{\bm{r}'} \right)}_{F(\bm{q}^2)}
\end{align}
形状因子是电荷分布函数的傅里叶变换，也就是电荷分布对入射轻子动量的响应。这个公式只在小动量转移的情况下成立，因为在大动量转移的时候，内部电荷会发生改变，且磁矩分布的影响开始显现。


\subsection{弹性散射的散射截面}

在最一般的情况下，也就是考虑相对论效应、质子质量有限（会反冲）以及自旋效应，轻子-核子的弹性散射截面由 Rosenbluth 公式给出。
\begin{theorem}[Rosenbluth 公式]
    电子与质子弹性散射的微分散射截面为：
    \begin{equation}
        \frac{\dd\sigma}{\dd\Omega} = \frac{\alpha^2 \cos^2\frac{\theta}{2}}{4E_1^2 \sin^4\frac{\theta}{2}} \frac{E_3}{E_1} \left[ \frac{G_E^2 + \tau G_M^2}{1+\tau} + 2\tau G_M^2 \tan^2\frac{\theta}{2} \right]
        \label{eq:rosenbluth}
    \end{equation}
\end{theorem}
公式中各项都有对应的物理意义：
\n{注意：相对论下的结构函数依赖于四维动量转移 $Q^2$ 而不是三维动量 $\bm{q}^2$。}
\begin{enumerate}
    \item \textbf{入射电子能量变化}：$E_3/E_1$ 项来源于质子的反冲效应，质子被撞飞带走了能量，导致出射电子能量 $E_3 < E_1$，极重靶核近似下该项为1。
    \item \textbf{结构函数}：
    \begin{itemize}
        \item $G_E(Q^2)$：\textbf{电形状因子}，描述电荷分布，在小动量转移情况下是电荷分布的傅里叶变换。
        \item $G_M(Q^2)$：\textbf{磁形状因子}，描述磁矩分布，在小动量转移情况下是磁矩分布的傅里叶变换。
    \end{itemize}
    \item \textbf{参数$\tau$}：衡量反冲程度，在公式中 $\tau$ 与磁形状因子 $G_M$ 绑定，随着 $Q^2$ 或者散射角升高，探测器对质子固有磁矩分布的敏感度增加。
\end{enumerate}

\subsection{形状因子的测量}

在不同的运动学区域，Rosenbluth 公式表现出明显的贡献占优特性：

\begin{itemize}
    \item \textbf{低动量转移区}（$\tau \ll 1$）：磁相互作用项被 $\tau$ 因子抑制，散射截面退化为主要由电形状因子决定：
    \begin{equation}
        \frac{\dd\sigma}{\dd\Omega} \approx \left(\frac{\dd\sigma}{\dd\Omega}\right)_{0} G_E^2(Q^2) \n{此处 $\left(\frac{\dd\sigma}{\dd\Omega}\right)_0$ 指代考虑靶核反冲修正后的莫特散射截面。}
    \end{equation}
    \item \textbf{高动量转移区}（$\tau \gg 1$）：由于质子强烈的相对论反冲，磁形状因子项占据主导地位，截面近似为：
    \begin{equation}
        \frac{\dd\sigma}{\dd\Omega} \approx \left(\frac{\dd\sigma}{\dd\Omega}\right)_{0} \tau G_M^2(Q^2) \left( 1 + 2\tan^2\frac{\theta}{2} \right)
    \end{equation}
\end{itemize}

形状因子 $G_E$ 和 $G_M$ 包含强子内部非微扰 QCD 动力学信息，目前主要通过电子-质子弹性散射实验测定。但是在一般的区域内，散射截面同时受电磁的影响，一般使用Rosenblith分离法测量。
\begin{derivationnote}[Rosenbluth 分离法]
定义约化截面 $\sigma_{\text{red}}$：
\begin{equation}
    \sigma_{\text{red}} \equiv \frac{\dd\sigma / \dd\Omega}{(\dd\sigma / \dd\Omega)_0} \cdot \epsilon(1+\tau) = \epsilon G_E^2(Q^2) + \tau G_M^2(Q^2)
\end{equation}
其中 $\epsilon = [1 + 2(1+\tau)\tan^2(\theta/2)]^{-1}$ 。\n{通过同步改变入射能量 $E_1$ 和散射角 $\theta$，可以在保持 $Q^2$不变的前提下调节 $\epsilon$ 值。}
以 $\sigma_{\text{red}}$ 为纵轴，$\epsilon$ 为横轴进行绘图，实验数据点将构成一条直线。该直线的斜率给出 $G_E^2(Q^2)$，而在 $\epsilon=0$ 处的截距则给出 $\tau G_M^2(Q^2)$。
\end{derivationnote}

\n{这是因为电磁分布和磁矩分布都源自夸克。}
实验测量发现，在较宽的 $Q^2$ 范围内，质子的电磁分布具有高度相似性，近似满足 $G_M(Q^2) \approx 2.79 G_E(Q^2)$。
\section{非弹性散射}

当入射电子的能量进一步提高，动量转移 $Q^2$ 增大到一定程度时，电子不仅会推动质子（弹性散射），甚至会将质子激发成共振态（如 $\Delta$ 粒子）或者直接将质子“打碎”，产生大量的强子末态。这种过程称为\textbf{非弹性散射}（Inelastic Scattering）。

\subsection{非弹性散射运动学}

在高能碰撞中，质子可能被“打碎”为末态强子系统 $X$，其总四动量记为 $p_4$，不变质量为 $M_X \equiv \sqrt{p_4^2}$。由于强子数守恒且质子是最轻的重子，末态质量必须满足 $M_X \ge M$。

为了描述此类动力学过程，引入四个相互关联的洛伦兹不变量：
\begin{itemize}
    \item \textbf{动量转移平方：} $Q^2 \equiv -q^2 > 0$。
    \item \textbf{比约肯变量：} $x \equiv \frac{Q^2}{2p_2 \cdot q}$，$0 < x \le 1$。
    \n{y和$\nu$是线性相关的}
    \item $y \equiv \frac{p_2 \cdot q}{p_2 \cdot p_1}$。该变量表征了实验室系下的能量损失率或质心系下的散射偏转：
    \begin{itemize}
        \item 实验室系：$y = \frac{M(E_1 - E_3)}{ME_1} = 1 - \frac{E_3}{E_1}$。 
        \item 质心系：在 $E \gg M$ 极限下，$y = \frac{1}{2}(1 - \cos\theta^*)$。 \n{其中 $\theta^*$ 为质心系散射角。}
    \end{itemize}
    \item \textbf{能量转移量：} $\nu \equiv \frac{p_2 \cdot q}{M}$。在实验室系下 $\nu = E_1 - E_3$，代表强子系统获得的能量。
\end{itemize}

实验的总能标由质心能平方 $s \equiv (p_1 + p_2)^2$ 决定。在极端相对论近似下，$s \approx 2p_1 \cdot p_2 + M^2$，由此可导出 $s - M^2 = 2p_1 \cdot p_2$。在给定 $s$ 的情况下，上述变量满足如下转换关系：
\begin{align}
    x &= \frac{Q^2}{2M\nu} \\
    y &= \frac{2M\nu}{s - M^2} \\
    xy &= \frac{Q^2}{s - M^2} \n{给定质心能后，仅需选取两个相互独立的变量（如 $x$ 和 $Q^2$）即可完整描述非弹性过程。}
\end{align}

非弹性散射与弹性散射在运动学上的核心差异在于自由度的释放。对于弹性散射，$M_X = M$ 强制要求 $x = 1$，此时只有一个独立变量；而对于非弹性散射，$M_X$ 的连续取值使得 $x$ 可以在 $(0, 1)$ 范围内变化，系统展现出两个独立的自由度。 \n{多自由度意味着在固定散射角 $\theta$ 时，出射电子能量 $E_3$ 不再唯一，而是对应一个连续的能谱分布。}

当入射电子能量极高时，质子不再保持完整，而是被“打碎”为由多个强子组成的末态系统 $X$。此时，末态强子系统的不变质量平方 $W^2 \equiv p_4^2$ 不再固定，而是满足 $W^2 > M^2$ 的连续分布。

\subsection{非弹性散射散射截面}

\paragraph{从形状因子到结构函数}

实验观测显示，弹性散射截面随动量转移 $Q^2$ 的增加而剧烈下降（约正比于 $Q^{-8}$），反映了质子作为整体时的弥散特征。然而，在深度非弹性散射（DIS）区域，散射截面随 $Q^2$ 的变化极其平缓。这种“标度无关性”表明电子实际上是与质子内部电荷分布集中、无空间结构的“点状组分”（即夸克）发生了弹性碰撞。

为了描述这一过程，我们需要将弹性散射的数学框架进行推广。弹性散射只有一个独立变量，其截面表现为一重微分形式 $d\sigma/dQ^2$；而非弹性散射由于末态质量 $W$ 可变，具有两个独立自由度，必须采用二重微分截面描述。

\paragraph{深度非弹性散射截面公式}

参考弹性散射中交换单光子的通用结构，非弹性散射的最一般洛伦兹不变截面形式可以写作：
\begin{equation}
    \frac{\dd^2\sigma}{\dd x \dd Q^2} = \frac{4\pi\alpha^2}{Q^4} \left[ \left(1 - y - \frac{M^2y^2}{Q^2}\right) \frac{F_2(x, Q^2)}{x} + y^2 F_1(x, Q^2) \right]
\end{equation}
\n{在极高能情形下，$Q^2 \gg M^2 y^2$，括号内的修正项通常可以忽略。}
此处，$F_1(x, Q^2)$ 和 $F_2(x, Q^2)$ 称为强子的\textbf{结构函数}，它们取代了弹性散射中的形状因子，用于描述质子内部组分的动量分布。在实验室系中，该公式可以转化为便于实验测量的形式：
\begin{equation}
    \frac{\dd^2\sigma}{\dd E_3 \dd\Omega} = \frac{\alpha^2}{4E_1^2 \sin^4(\theta/2)} \left[ \frac{1}{\nu} F_2(x, Q^2) \cos^2\frac{\theta}{2} + \frac{2}{M} F_1(x, Q^2) \sin^2\frac{\theta}{2} \right]
\end{equation}
\n{利用出射电子能量 $E_3$ 和散射角 $\theta$ 可唯一确定 $x$ 和 $Q^2$。}

\paragraph{结构函数的物理意义}

结构函数揭示了核子内部的动力学响应特征：
\begin{itemize}
    \item \textbf{$F_2(x, Q^2)$（电磁结构函数）：} 与 $\cos^2(\theta/2)$ 项关联，主要反映了质子内部组分的电荷分布。它在形式上对应于弹性散射中电形状因子与磁形状因子的综合贡献。
    \item \textbf{$F_1(x, Q^2)$（磁结构函数）：} 与 $\sin^2(\theta/2)$ 项关联，代表了“纯”磁性响应。它直接与组分的自旋翻转过程相关，是探测组分自旋性质的核心量。
\end{itemize}


\section{深度非弹性散射 (DIS) 与部分子模型}

当动量转移 $Q^2 \to \infty$ 且能量转移 $\nu \to \infty$（保持 $x$ 固定）时，我们进入了\textbf{深度非弹性散射（Deep Inelastic Scattering, DIS）}区域。在此区域，实验观测到了两个极其重要的现象，直接揭示了夸克的存在。

\textbf{1. 比约肯标度无关性 (Bjorken Scaling)}

实验发现，在高能极限下，结构函数 $F_1, F_2$ 几乎不再依赖于 $Q^2$，而只依赖于无量纲变量 $x$：
\begin{equation}
    F_1(x, Q^2) \to F_1(x), \quad F_2(x, Q^2) \to F_2(x)
\end{equation}
这表明质子内部的组分是点状的（point-like）。如果组分有大小，随着 $Q^2$ 增大（波长变短），电子会看到更精细的结构，导致结构函数随 $Q^2$ 变化（如弹性散射中的形状因子迅速衰减）。标度无关性意味着无论分辨率多高，看到的都是同一个点。

\textbf{2. Callan-Gross 关系}

实验进一步证实，$F_1$ 和 $F_2$ 之间满足如下关系：
\begin{equation}
    2x F_1(x) = F_2(x)
\end{equation}
这一关系是部分子自旋性质的直接判据。
\begin{itemize}
    \item 若部分子自旋为 0（标量），则没有磁相互作用，预言 $F_1 = 0$。
    \item 若部分子自旋为 1/2（费米子），则预言 $2x F_1 = F_2$。
\end{itemize}
实验数据完美符合 Callan-Gross 关系，确凿地证明了质子内部的点状组分（夸克）是自旋为 1/2 的费米子。
