# 1.对称性
在同位旋对称性中：
- 每个不可约表示用一个$\color{red}I$表示，不可约表示的不同分类用$\color{red}I_3$区分；
- 粒子按不可约表示分类，每个粒子是一个分量；
- 同一个不可约表示中粒子的$\color{red}J^{P}$相同；
- 同一个不可约表示中粒子质量近似相同，宽度近似相等；
- 同一个不可约表示下，一个粒子存在则其他粒子也存在；
- 强相互作用下，奇异数和重子数守恒，粒子的超荷$Y = \frac{1}{2}(S+b)$确定；
- 那么对于一个强子，其为同位旋第三分量$SU(2)$和超荷$U(1)$的本征态；
寻找一个群$G$使得$SU(2)\otimes U(1) \subset G$，这就是强子所属的更大的对称性。在一系列我看不懂的数学之后，G应该是$SU(3)$。

# 2.夸克模型
- Sakata模型可以解释介子的$SU(3)$分类，但是解释重子分类遇到困难。这是因为由于重子数守恒，重子必需由两个坂田子和一个反坂田子组成。
- Gellmann的八正法对介子和重子的分类都很成功，但是其假设重子和介子都是$SU(3)$的八重态或由其直乘分解得到，而八重态不是SU3的基础表示。（就是说拼装粒子的积木不是最基本的块块而是组合的块块）。
- 由此只能找出$SU(3)$的基础表示，认为这些基础表示也对应着粒子，称为夸克(u、d、s)，其共轭表示是反夸克。
